# Elemix web

Landing, privacy and support pages for the Elemix iPhone game, served at https://elemix.ardasnturk.com via GitHub Pages.

- English pages at the root, Turkish under `/tr/`.
- Pages are generated by `build.py`; edit the texts there and run `python3 build.py`.
- Privacy: `/privacy/` · Support: `/support/` (used by App Store Connect).
